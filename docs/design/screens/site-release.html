2.27.0

Published November 19, 2026Current release
npm install @photivra/engine@2.27.0

A minor release: lower CPU cost of the display view with lens corrections and sharpening (#649), with camera rotation under a rolling shutter and defocus (#651), of defocused and long-lens Quality frames (#653), with catalogue lenses (#655, CPU) and with develop options (#656), and layered chart scenes (#652). Measured before and after below and in docs/DISPLAY_VIEW.md, “2.27.0 cost cases”. See the 2.27.0 release record.

  • Changed (fast defaults): two new fast methods with full methods kept (registry entries motion.shutter.rolling/view-row-bands and lens.catalogue/view-uniform-window), and the fast rule of output.highlightMode.reconstruct/view-moments (3 or 6 points per axis instead of 6). Each is the default for the display view and sRGB samples; fast: false (and the record’s own flag) takes the full method.
  • New fields: view.defocus.rollingBands: { rows, shiftSites }, view.lensPsf.uniformWindows, and view.rendering.chainPointsPerAxis: "3-or-6" on fast requests (16 with fast: false, as before).
  • New (#652): layered chart scenes. scene: { kind: "layered-chart", cards, backPlane? } (opaque fronto-parallel cards at several distances in front of an optional back plane with point lights) in simulateCapture, simulateIdealReference, simulateDisplayView and prepareDisplayView, after prepareLayeredChartScenes().
